## `perf`

```bash
uv run excelbench perf --tests <fixture-dir> --output <output-dir> [options]
```

Measures read and write throughput (ops/second) plus RSS memory for each adapter.

### What It Measures

For each library, the perf runner captures:

| Metric | Description |
|--------|-------------|
| Wall time | Elapsed real time (p50, p95, p99) |
| CPU time | User + system CPU time |
| RSS delta | Memory usage increase |
| Throughput | Operations per second (cells read/written) |

### Benchmark Workloads

- **Per-cell read** — iterate cells one at a time (10K cells)
- **Per-cell styled read** — read with formatting attributes (1K cells)
- **Bulk read** — `read_sheet_values()` returning all cells at once (10K cells)
- **Bulk write** — `write_sheet_values()` writing all cells at once (100K cells)

Bulk workloads run only on adapters that implement `read_sheet_values()` or `write_sheet_values()`; for other adapters the harness records the bulk operation as failed. The WolfXL adapter implements both through WolfXL's public worksheet API, not a separate bulk path.

### Options

| Flag | Default | Description |
|------|---------|-------------|
| `--tests` | required | Path to throughput fixture directory |
| `--output` | required | Output directory for perf results |
| `--adapters` | all | Comma-separated adapter names |
| `--iterations` | 5 | Number of iterations per workload |

### Example

```bash
uv run excelbench perf --tests fixtures/excel --output results
```

### Reference Numbers

From the 2026-10-03 perf snapshot (`results-2026-10-03/perf/README.md`): Apple M4 Pro, Python 3.12.3, warmup 3, 25 iterations, the same 19 xlsx features for every library. Totals are sums of per-feature p50 wall times; the multiple is openpyxl's total divided by the library's total.

| Library | Read p50 total | Read vs openpyxl | Write p50 total | Write vs openpyxl |
|---------|----------------|------------------|-----------------|-------------------|
| WolfXL 2.0.8 | 13.90 ms | 1.73x | 11.26 ms | 2.45x |
| openpyxl 3.1.5 | 24.01 ms | 1.00x | 27.59 ms | 1.00x |
| python-calamine 0.8.2 | 1.73 ms | 13.92x | n/a (read-only) | n/a |
| polars 1.44.2 | 6.21 ms | 3.87x | n/a (read-only) | n/a |
| pandas 3.0.6 | 29.33 ms | 0.82x | 28.57 ms | 0.97x |

WolfXL is measured through its public API (`wolfxl.load_workbook`, `wolfxl.Workbook`), the same kind of surface as every other library. It reads 1.73x and writes 2.45x faster than openpyxl on this workload. python-calamine (13.92x) and polars (3.87x) read faster than WolfXL. openpyxl reads and writes faster than pandas.
